# **App Name**: IronTrader

## Core Features:

- Discipline Thresholds: Configure loss-limit sliders and trade frequency caps with real-time validation feedback.
- AI Reality-Check (Fact-Bomb): A tool that uses generative AI to analyze trade logs and deliver brutal, data-driven critiques of trading psychology and bad habits.
- Live Cooldown Enforcement: Sticky banner system that tracks and enforces mandatory breaks based on breach of disciplinary rules.
- High-Volume CSV Processor: Progressive file uploader for batch trade history ingestion with drag-and-drop support and error detection.
- Performance Analytics Suite: Responsive dashboards for win rates and MDD (Maximum Drawdown) with granular period filtering.
- Snap-Scan Trade Logs: Chronological trade cards optimized for sub-3-minute review cycles focusing on key metrics and entry/exit insights.
- Authenticated Vault: Secure account management and private storage for personal trade data and strategies.

## Style Guidelines:

- Primary Color: Electric Indigo (#8a70ff) - chosen for its tech-forward, high-intensity aesthetic suited for trading professionals.
- Background Color: Obsidian Night (#14131a) - a deep, desaturated variant of the primary hue providing a focused, dark-themed command center.
- Accent Color: Azure Frost (#8ab2ff) - an analogous sky blue that provides high-contrast secondary signals without visual fatigue.
- Headline Font: 'Space Grotesk' (Sans-serif) - used for its computerized, scientific feel for headers and charts.
- Body Font: 'Inter' (Sans-serif) - provides an objective, machined look for dense financial data and status readouts.
- Lean, line-based iconography from shadcn/ui to maintain a minimalist, performance-driven look.
- Low-latency micro-interactions and horizontal drawer transitions to emphasize the 'speed-of-light' trading environment.
